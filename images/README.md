## Replacing with Real Images (Optional)

If you want to replace these placeholder SVG images with real photographs or official logos:

### For University Logos:
1. Visit the official SUT website: https://www.sut.ac.th/
2. Download official logo files
3. Save them as `sut_logo.png` or `sut_logo.jpg`
4. Update the HTML `<img src="images/sut_logo.svg">` to use the new filename

### For Medical Images:
You can download real fundus photographs from:
- **National Eye Institute (NEI)**: https://www.nei.nih.gov/
- **Kaggle Diabetic Retinopathy Dataset**: https://www.kaggle.com/c/diabetic-retinopathy-detection
- **Open access medical journals** (ensure proper licensing)

Replace `dr_fundus.svg` with actual fundus photographs.

### For AI Company Logos:
Download official logos from:
- **ChatGPT/OpenAI**: https://openai.com/brand
- **Anthropic (Claude)**: https://www.anthropic.com/
- **Google Gemini**: https://about.google/ or use Google brand guidelines
- **Perplexity**: https://www.perplexity.ai/

## Image Requirements

- **Format**: SVG (scalable), PNG (with transparency), or JPG
- **Resolution**: At least 1000px wide for charts/diagrams
- **License**: Ensure you have permission to use any images in presentations
- **File size**: Keep under 500KB per image for fast loading
